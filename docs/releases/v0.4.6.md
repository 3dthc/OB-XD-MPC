## Changes

- **Projects remember the sound.** A saved project keeps OB-Xd's bank, patch, every knob, the tuning and the theme,
  and a reload brings them back in one go. The bank is found by its file and the patch by its name, so adding banks
  to `my-banks` doesn't change which one a project opens.
- **Five new themes:** Ocean, Violet, MPC Black (red displays on ash black), Tangerine and Jade. BROWSE gets its own
  look in each.
- **Header:** the BANK and PATCH arrows are thin chevrons inside the displays, which are wider. The BPM readout moves
  to the top right of SETTINGS.
- **More patches, plain names.** The converted banks lose the "CC0" in their names (Keys, Bass+Lead, Pads+FX) and
  six banks now ship: three more (Keys 2, Bass+Lead 2, Pads+FX 2) with about 310 extra patches in the style of OB-Xd's
  own factory sounds. These use a few OB-Xf features OB-Xd lacks (xpander filter, ring mod, second LFO), mapped to the
  nearest OB-Xd equivalent, so they are close to the originals rather than exact. Projects saved with the old bank names
  still load their patch. Credits: `banks/CREDITS.md`.

## Fixes

- MPC no longer resets the sound around load, save and STOP. It pokes the Bank control to the end of its range then,
  which loaded the last bank's first patch over your sound.
- Reopening a project no longer loads a different patch when it was saved with BROWSE looking at another bank, and no
  longer opens a file list when it was saved with LOAD BANK / LOAD PRESET open.
- Loads on Gen1 MPCs running MPC OS 2.x. 0.4.5 needed a newer C++ runtime than MPC OS 2.x has (`version
  'GLIBCXX_3.4.29' not found`); the build now uses the older runtime (GLIBCXX 3.4.28 at most) and still loads on MPC OS 3.x.
