## Changes

- **More patches, plain names.** The converted banks lose the "CC0" in their names (Keys, Bass+Lead, Pads+FX) and
  three more banks join them (Keys 2, Bass+Lead 2, Pads+FX 2) with about 310 extra patches in the style of OB-Xd's own
  factory sounds. These use a few OB-Xf features OB-Xd lacks (xpander filter, ring mod, second LFO), mapped to the
  nearest OB-Xd equivalent, so they are close to the originals rather than exact. Projects saved with the old bank
  names still load their patch. Credits: `banks/CREDITS.md`.

## Fixes

- Reopening a project on a bank that has two patches with the same name loads the patch it was saved on, not the first
  one with that name.
