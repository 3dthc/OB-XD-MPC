## Changes

- **More patches, plain names.** The converted banks lose the "CC0" in their names (Keys, Bass+Lead, Pads+FX) and
  five more banks join them (Keys 2, Bass+Lead 2, Pads 2, Strings+Brass 2, FX+Drums 2) with about 390 extra patches in the
  style of OB-Xd's own factory sounds, including the Voices and Atmospheres categories, drums and percussion. These use a few OB-Xf features OB-Xd lacks (xpander filter, ring mod, second LFO), mapped to the
  nearest OB-Xd equivalent, so they are close to the originals rather than exact. Projects saved with the old bank
  names still load their patch. Credits: `banks/CREDITS.md`.
- **Classics bank.** 35 patches written from scratch for this plugin: brass stabs and swells, string machines, PWM and sweep
  pads, acid / sub / pluck basses, sync and glide leads, short plucks that suit the MPC's arpeggiator, and effects (zap,
  riser, wind). Levels evened out like the others; not yet auditioned by ear.

## Fixes

- Reopening a project on a bank that has two patches with the same name loads the patch it was saved on, not the first
  one with that name.
- Keys 2 and the other new banks no longer show two patches under one name. OB-Xf numbers its accordions and rotary
  organs differently inside the files than by file name, so two different sounds both read "Accordion 1"; the new
  banks now use the file name.
